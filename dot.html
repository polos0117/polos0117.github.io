SPRITE도트 공방

공방 모음

다섯 공방의 인물을 도트로. ① 인물을 고르고 ② 정지 → 대기 → 걷기 → 반응 차례로 「그린다」 ③ 「정리하기」 → 「다음」, 넷 다 되면 「받기」. 위 「지금 할 일」이 다음 단추를 알려 준다. 정리는 이 브라우저 안에서만(「그린다」만 첨부와 지시문을 OpenAI 로 보낸다) — 저장소에 올리기는 세션이 검토한 뒤에 한다.

1인물

공방을 고르면 그 공방 도감에 등록된 인물이 뜬다. 인물을 누르면 그 인물의 그림이 아래에 — 정본(얼굴·머리·색)과 의상을 짚는다.

      2그리기

      정지 → 대기 → 걷기 → 반응 차례로. 정지 도트가 마음에 든 뒤에 동작으로 간다 — 동작은 정지 도트 6배를 첫 첨부로 붙인다. ○ 아직 · ◐ 원본 있음 · ● 정리됨

      열쇠·모델

      누르면 지시문과 첨부(정본·의상·정지 도트 6배·다리 안내·1칸 원본)가 gpt 그림 API 로 간다. 본보기(같은 공방의 정지 도트 6배)는 손으로 붙일 때만.

      다리 자세 안내 받기

      지시문을 직접 쓴다 — 열쇠 없이 GPT 채팅에 붙여 넣을 때 (받은 PNG 는 ③ 「파일로 넣는다」)

        3정리

        받은 원본을 격자·색으로 정리해 96×128 칸에 앉힌다. 「그린다」로 받았으면 원본은 이미 들어와 있다 — 「정리하기」만 누른다.

        파일로 넣는다 — 원본 PNG(자르거나 줄이지 않은 것) · 동작 시트면 정지 도트 정리본도
        생성 원본아직 없다
        정지 도트 (동작 시트만)아직 없다 — 여기서 정지를 정리하면 그것을 쓴다

        정리 값 (기본값은 book 서재 세 인물이 쓴 값)

        재생

        정리본

        칸 고르기 — 누르면 재생에서 빠지고 다시 누르면 끝에 붙는다. 차례·시간은 글로도 고친다(앨리스 대기는 0,3,0,2)

        손보기 — 생성기가 다리를 안 바꿔 줄 때: 앞 반 주기를 뒤로 복사하고 붓·두 색 맞바꾸기로 다리 표시를 옮긴다
        색 A색 B

        누르거나 끌어 칠한다. 손본 것은 바로 정리본에 들어가고 걷기 빠르기·dy 를 다시 센다 — 기록에 손본 횟수가 남는다.

        무대 — 이번에 정리한 상태를 모아 공방에서처럼 (누르면 반응)

        받기 — 정리한 것을 모두. 받은 것을 세션에 주고 "올려 줘" 하면 그림 저장소·sprites.json 에 올린다
